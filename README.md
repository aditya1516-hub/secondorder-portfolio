# SecondOrder

SecondOrder is a working prototype for practicing strategic decisions under uncertainty. Participants step into a leadership role, review a company scorecard, make decisions, consult a boardroom, and respond to emerging emergencies. The simulation models trade-offs and second-order effects rather than a simple win-or-lose result.

**[Explore the live prototype](https://secondorder-simulation.vercel.app/)**

## Featured case

The boAt-inspired business case explores growth, margins, product strategy, operating readiness, customer trust, and stakeholder confidence. It is an independently developed educational simulation, not live company data or an endorsement by boAt.

## What is included

- A guided introduction and case briefing.
- A decision desk with business choices and modeled consequences.
- Company scorecards, a boardroom consultation, and a timed emergency.
- A final review and downloadable report.
- An optional AI-assisted mode on the hosted prototype. The simulation's business outcomes are rule-based; AI is a separate interpretive layer.

## About this repository

This public portfolio snapshot contains the browser-facing website and simulation files in `public/`. Production services, founder analytics, secrets, and participant records are not included. The snapshot is provided for inspection; it is not a complete deployment of the hosted backend. Run the static files through a local web server to explore the standard interface. Optional hosted AI features require separate server configuration.

This is a prototype. Simulated metrics and illustrative examples should not be interpreted as validated assessments, real financial data, or evidence of learning outcomes.
